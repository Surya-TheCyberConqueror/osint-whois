# OSINT WHOIS Tool 🔍

**Surya – The Cyber Conqueror**

A powerful Bash-based OSINT WHOIS tool designed for cybersecurity professionals, bug bounty hunters, and OSINT researchers.

## 🚀 Features
- Domain WHOIS lookup
- Domain age analysis
- HTTPS / SSL check
- HTTP headers inspection
- Email capability detection
- WHOIS privacy detection
- Possible use case inference
- Color-coded OSINT output

## 🛠 Requirements
- Linux (Kali recommended)
- whois
- curl
- openssl

## 📦 Installation
```bash
git clone https://github.com/Surya-TheCyberConqueror/osint-whois.git
cd osint-whois
chmod +x install.sh
./install.sh
